# Mehmet Arda Web Tasarım

Frontend-only profesyonel ajans sitesi.

## Dosya Yapısı

- `index.html`
- `styles.css`
- `script.js`
- `assets/` ileride görsel, video veya backend bağlantı dosyaları için ayrıldı.

## Özellikler

- Glassmorphism kartlar
- Video background hero
- Background beams with collision sahnesi
- Dark/light mode ve `localStorage` kaydı
- Bootstrap dropdown ve mobil menü
- Gooey arama inputu
- Macbook showcase bölümü
- Apple glass image cards ve mouse tilt efekti
- Animasyonlu sosyal medya ikonları
- Encrypt scramble efektli aksiyon butonları
- Sidebar müşteri paneli önizlemesi
- Popup detay modalı
- GSAP scroll animasyonları
- Chart.js yetenek grafikleri
- Lottie hero animasyonu
- Proje filtreleme ve lightbox
- Formspree iletişim formu: `https://formspree.io/f/xeevzely`
- WhatsApp destek balonu: `https://wa.me/905314668927`
- SEO meta, Open Graph ve schema
